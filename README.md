# SIM-PUNCHLIST — Kelompok 4 Teknik Industri Universitas Pamulang

Aplikasi Web **Sistem Monitoring Punch List Berbasis Web untuk Mengurangi Keterlambatan Penyelesaian Masa Pemeliharaan Proyek Konstruksi** yang telah disesuaikan sepenuhnya dengan dataset & spesifikasi pada **Laporan Akhir Capstone Design Kelompok 4 (2026)**.

## Daftar File
- `index.html` — Antarmuka lengkap (Login RBAC, Dashboard KPI, Data Punch List, Early Warning System, Laporan Bergambar FHO, Manajemen User, Sinkronisasi Firebase)
- `style.css` — Desain responsif & layout cetak Berita Acara FHO
- `app.js` — Logika bisnis, 15 dataset studi kasus BAB I (`PL-001` s.d. `PL-015`), validasi Poka-Yoke foto Before–After, dan integrasi Firebase Realtime Database
