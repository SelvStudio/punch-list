Koneksi Firebase Realtime Database (Lintas Jaringan)

Agar aplikasi web yang di-hosting di GitHub Pages dapat diedit dan dipantau secara real-time dari HP dan Laptop dengan jaringan internet berbeda, masukkan URL Firebase Realtime Database Anda di bawah ini.

Pencadangan & Pemulihan Data (Backup / Restore)

Gunakan fitur ini untuk mencadangkan seluruh data punch list beserta foto Before–After atau memulihkan 15 data studi kasus latar belakang.

Panduan Hosting Online di GitHub Pages

  1. Buat Repositori Baru di GitHub: Buka github.com, buat repository publik baru (misalnya sim-punchlist).
  2. Unggah 3 File Utama: Unggah file index.html, style.css, dan app.js ke dalam root repositori tersebut.
  3. Aktifkan GitHub Pages: Masuk ke menu Settings → Pages, pada bagian Branch pilih main dan folder / (root), lalu klik Save.
  4. Aktifkan Database Real-Time Lintas Jaringan: Buka console.firebase.google.com → buat Realtime Database → atur tab Rules menjadi ".read": true, ".write": true → tempel URL database pada kolom di samping.
