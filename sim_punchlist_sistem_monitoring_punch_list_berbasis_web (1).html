Cara Mengonlinekan Aplikasi di GitHub Pages

  1. Buat Repository Baru di GitHub: Buka github.com/new, beri nama misalnya sim-punchlist-kelompok4, pilih Public, lalu klik Create repository.
  2. Unggah File Ini sebagai index.html: Klik uploading an existing file, unggah file HTML ini dengan nama persis index.html, lalu klik Commit changes.
  3. Aktifkan GitHub Pages: Masuk ke tab Settings → Pages, pada bagian Branch pilih main dan folder /(root), lalu klik Save.
  4. Akses Online Lintas Jaringan: Dalam ±1 menit, aplikasi web Anda dapat dibuka dari HP maupun laptop mana saja melalui alamat https://username-anda.github.io/sim-punchlist-kelompok4/.
